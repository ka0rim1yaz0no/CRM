# Billable Coaching

Coaching can start during an assigned shift. It is billable, has no time limit,
and does not consume the ordinary Off the Phone allowance or create a payroll
deduction. Coaching Out returns the employee to Online. Starting or ending
Coaching uses the existing attendance command and audit rules.

Coaching blocks Auto Call. An explicit manual call can still proceed when the
normal Bridge, lead ownership and call-safety checks pass. Returning Online
does not bypass those checks or end an existing call.

Employee Dashboard shows elapsed Coaching time for the shift separately from
the remaining Off the Phone allowance. Attendance, HR/Profile and Call
Dashboard retain Coaching labels and durations. Coaching does not rewrite
original punches or saved Paid/Completed amounts, statuses or dates.
