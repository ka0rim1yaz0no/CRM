Data Check will be read-only, signed-full-admin-only, independently recompute from projected raw collections, and label reused screen adapters / shared boundary logic. Historical disconnect gaps, missing immutable heartbeat/version history and unavailable per-screen values must be cannot-verify rather than invented zeros or a false PASS. No real employee/customer data or uploads were inspected for this audit.
